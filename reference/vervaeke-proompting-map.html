Core concepts

Vervaeke conceptOne-line meaningProompting constructCode / doc anchor
Relevance realization (RR) Zeroing in on what matters now, out of an intractable space of things that could matter. Cannot be computed by fixed rule (the frame problem) — only realized by balancing opposing constraints. Relevance Realization — the one faculty behind every "what matters right now?" judgement a Persona makes. Runs at four timescales (below). CONTEXT.md § Relevance realization; ADR 0015
Salience What grips attention, bottom-up. Distinct from importance (weight to goal) and relevance (fit to task). Salience — pull from the Arena on a Persona, always relational. Scored in the stop-signal race; ranks Recall. backend/Services/Memory/SalienceMath.cs; PersonaSalienceService.cs
Salience landscape The contoured field of what looms large vs. fades, reshaped by use. A Persona's memories under the salience ranking — recalled ones strengthen, untouched ones sink. SalienceMath.Score: weight × decay + use_bonus
Opponent processing RR is implemented as tension between competing constraints, neither globally right (efficiency⇄resiliency, exploration⇄exploitation). Structural tensions kept structural: two-arm recall quota (relevant⇄recent), net pressure (urge pull ⇄ round/self penalties), stop-signal race (finish⇄interrupt). ADR 0015 § two-arm recall; UrgeMath.CalculateNetPressure; RaceTrigger.cs
Parasitic processing RR gone malignant: a misframing that feeds itself — each distorted interpretation becomes the lens for the next (reciprocal narrowing). The rejected serial import chain (scene N reads scenes 1..N−1 back from AGE) — errors became framing for later scenes. Cure: stateless map, registry carries nouns not narrative, side-effect-free regeneration, human gate. ADR 0017 § "Why map, not scan"; SceneMapService.cs
Agent–arena coupling Agent and world co-define each other; the arena affords actions to this agent. Meaning lives in the relation. Arena — the shared stage per Party. Entities are persona-independent; each Persona's memory is their edges to the Arena, never properties of the entities. CONTEXT.md § Arena; ADR 0014, ADR 0004/0006 (AGE graph)

Import (ADR 0017) is Capture in batch: same weight bet ("would this stick?"), plus a human-flippable weight floor (below → Room history only, no Event), 4P routing (episode → Event+Recollections, trait → persona card, rule → discarded-with-reason), no Stances at import (beliefs crystallize in rest via Consolidation), and anchor-as-vividness (anchor timestamp places memories on the decay curve; 30-day anchor ≈ 38× salience gap). Conservation ledger keeps the lossiness auditable. See lesson 2.

Design rules that follow from the framework

  • Never collapse an opponent process into one tuned formula without an eval harness to tune against (ADR 0015 rejected weight × decay × relevance_boost for the quota union).
  • Attention strengthens, exposure doesn't — recall_count increments only on the Decision phase's pick, not on surfacing in the prompt.
  • Beliefs crystallize in rest, not in the moment — Capture writes propositional + perspectival only; Stances come later via Consolidation.
  • The personal view lives on edges, never on entities — memory is a relation to the Arena (agent–arena).
  • Wall-clock decay — the world stays alive while you're away; wall-clock is the only clock users can intuit.
  • Zero hot-path LLM calls for memory — ≤2 LLM calls per beat (Decision + Speaking); everything RR-adjacent is arithmetic or runs in rest.
