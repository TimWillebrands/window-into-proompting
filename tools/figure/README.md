# Figure rig

`bake-rig.mjs` turns Quaternius' Universal Animation Library into `skeleton.gen.json` and `clips.gen.json` in
`frontend/src/apps/places/figure/`. Licence: CC0 1.0 (https://quaternius.com/packs/universalanimationlibrary.html).

1. Download the Standard pack from https://quaternius.itch.io/universal-animation-library
2. `node tools/figure/bake-rig.mjs "<pack>/Unreal-Godot/UAL1_Standard.glb"`

The clip list and its names are at the top of the script.
